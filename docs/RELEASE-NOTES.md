Akeno ColorVision makes confusing colors (many reds, greens, browns and grays) easier to tell apart by applying a color transform to the whole Windows screen.

**Download:** `Akeno-ColorVision-v…-win-x64.zip` (portable — unzip and double-click `AkenoColorVision.exe`), or the optional `Akeno-ColorVision-Setup-v….exe` installer (per-user, no admin rights).

**First start:** Windows SmartScreen may warn because the executables are not code-signed. Click *More info → Run anyway*. Verify the download with the `.sha256` file if you like.

**Emergency reset:** `Ctrl + Alt + Shift + Backspace`, the *Reset colors* button, or `AkenoColorVision-EmergencyReset.exe`.

**Honest status:** compiled and automatically tested on Windows in CI (unit tests and real Magnification API round-trip tests). Visual behaviour on a real monitor and inside Minecraft has **not** yet been verified for this version — please follow the checklists in `docs/TESTING.md` and report results. See `CHANGELOG.md` for details and known limitations.
